# Respuestas - Trabajo Práctico Comparable y Comparator

**Pregunta 1: ¿Por qué `Collections.sort()` no compila cuando le pasamos una `List<Estudiante>`? ¿Qué contrato exige Java que nuestra clase no está cumpliendo?**
`Collections.sort()` no compila porque el método genérico exige que los elementos de la lista implementen la interfaz `Comparable<? super T>`. Java requiere este contrato para establecer una relación de orden total entre los objetos; sin la implementación del método `compareTo()`, el compilador carece de una semántica de comparación que le permita determinar la precedencia posicional entre dos instancias de la clase `Estudiante`.

**Pregunta 2: ¿Por qué elegiste el atributo `promedio` como orden natural? ¿Qué pasaría si mañana un nuevo requisito pide ordenar por `cantidadMateriasAprobadas`? ¿Modificarías `compareTo`? ¿Qué consecuencias tendría?**
Se seleccionó el `promedio` por ser el atributo primario de mérito académico en el contexto universitario. Si existiese un nuevo requerimiento para ordenar por `cantidadMateriasAprobadas`, modificar el método `compareTo` afectaría a todas las partes del sistema que dependan implícitamente de este ordenamiento previo. Alterar el orden natural altera el comportamiento global de colecciones como `TreeSet` o `TreeMap` que operan con dicha clase, violando así la estabilidad del sistema.

**Pregunta 3: `Comparable` nos ata a un único criterio de ordenamiento. ¿Qué problemas de diseño introduce esto si nuestro sistema necesitara ordenar la misma lista de estudiantes de 4 formas distintas según el contexto? Relacioná tu respuesta con los principios de responsabilidad única (SRP) y abierto/cerrado (OCP).**
Implementar múltiples lógicas condicionales dentro de `compareTo()` violaría el Principio de Responsabilidad Única (SRP), ya que la entidad de dominio asumiría el control de reglas de presentación de la capa de negocio. Adicionalmente, violaría el Principio Abierto/Cerrado (OCP), debido a que cada nuevo criterio de ordenamiento requeriría la modificación del código fuente de la clase `Estudiante`. Las entidades de dominio deben estar cerradas a la modificación de criterios de ordenamiento específicos del contexto.
